# Course Builder：上下文隔离与 Beamer 生成

[English](CASE-STUDY-BEAMER.md) | 简体中文

记录日期：2026-10-03。使用环境：pi-own Course Builder、pi-CAW 0.2.30，生成模型通过 Pi 绑定为 `grok-4.7`。

## 使用效果

原来的长聊天同时承担协调、材料读取、源码生成和编译反馈，工具调用反复携带历史与已经读取的材料。

Workflow 将生成任务放入独立 worker，只载入所选课程素材、当前任务要求和必要的修订基线。Main worker 继承发起 Pi 聊天的模型和 thinking；编译修复节点接收准确源码与日志。

实际使用反馈：上下文隔离解决了反复读取长对话的问题，模型更专注于当前任务，内容展开更多，Beamer 的组织和质量也更高。

首次隔离写稿的非推理输出多约 **20.6%**，费用低约 **93.4%**；包含一次编译反馈修复后，费用低约 **86.4%**。上下文携带量明显下降，更多输出用于展开当前任务。

非推理输出包含生成源码和工具参数。费用来自所选生成与修复步骤的模型 usage。
